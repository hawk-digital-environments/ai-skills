## What to write in the skill:

> IMPORTANT: This is a global skill that should not contain any project-specific instructions.

This skill contains information about how we want to write laravel code and how we want to structure our laravel projects. It is meant to be a general guide for anyone working with laravel in our projects, not just for a specific project.

Do not include any frontend related information in this skill, even if it is mentioned in the source documentation. This skill should only contain backend related information.

Testing is also covered in a separate skill, so do not include any testing related information in this skill, except if the pattern is specific to laravel and cannot be easily applied to other frameworks. In that case, include the pattern but do not include any testing related information that is not specific to laravel.
