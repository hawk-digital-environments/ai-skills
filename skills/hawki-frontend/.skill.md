## What to write in the skill:

This skill is highly project-specific and should contain instructions on how to write the frontend code for the HAWKI project.

The skill must start with the following passage:

```
> ONLY CONTINUE IF THE `svelte` SKILL IS AVAILABLE.
> This skill builds on top of the `svelte` skill, it is imperative that you have read and understood the `svelte` skill before writing this one. If you haven't, please stop and read it first. If you don't have the `svelte` skill available, report an error: "The `svelte` skill is required to write the `hawki-frontend` skill."
```

Exclude everything that is available in the [svelte skill](../svelte/SKILL.md) (read the file before you continue), and only include information that is specific to the HAWKI project.
